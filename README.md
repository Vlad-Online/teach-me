# teach-me

Тренажёр европейского португальского по коротким клипам из живой речи.
Живёт в трее, время от времени показывает у часов клип на 2–5 секунд: надо сказать перевод на русский.
Подробности дизайна — в [DESIGN.md](DESIGN.md).

## Что нужно

- Rust (MSVC), ffmpeg, Node.js (нужен yt-dlp для YouTube), `yt-dlp` (`pip install -U yt-dlp`).
- `config.toml` (создаётся из `config.example.toml`, не попадает в git):
  - `[anthropic] api_key` — Claude Haiku 5.5: перевод и разбор фраз, проверка варианта языка (pt-PT),
    поиск вшитых субтитров, проверка ответов. Провайдер переключается в `[llm] provider` (anthropic | openai).
  - `[openai] api_key` — только распознавание речи (`gpt-4o-mini-transcribe`).

## Сбор базы

```
cargo run --release -p harvester -- discover      # новые видео из sources.toml + их субтитры
cargo run --release -p harvester -- mine -c 30    # отобрать 30 фраз и нарезать клипы
cargo run --release -p harvester -- mine --dry-run   # посмотреть кандидатов без API
cargo run --release -p harvester -- import        # свои видео из папки inbox/
cargo run --release -p harvester -- run -c 30     # всё сразу
cargo run --release -p harvester -- stats
cargo run --release -p harvester -- check-api     # проверить ключи и модели реальными запросами
```

Что делает `mine`:
1. Режет автосубтитры на законченные реплики по пунктуации, паузам и смене говорящего.
2. Оценивает частотность слов, пар и троек слов и целых фраз по всему корпусу.
3. Модель OpenAI ставит оценку полезности для уровня A2–B1, отбираются лучшие с ограничениями
   на видео, канал и одинаковое начало фразы.
4. Видео скачивается в 480p, клип вырезается и нормализуется по громкости. Если в кадре вшитые
   субтитры, они размываются (проверка по кадру моделью с vision).
5. Клип распознаётся заново (`gpt-4o-mini-transcribe`), модель пишет точный текст, перевод,
   варианты перевода и короткий разбор.
6. Скачанное видео удаляется (`keep_videos = false`).

Клипы лежат в `data/clips/`, база — `data/teach-me.db` (SQLite).

## Тренажёр

```
cargo run --release -p teach-me            # в трей
cargo run --release -p teach-me -- --now   # сразу открыть карточку
```

- Карточка всплывает раз в `interval_minutes` в активные часы; не всплывает, если вы отошли
  от компьютера или запущено полноэкранное приложение/презентация.
- `Ctrl+Space` (пока открыта карточка): держите и говорите перевод, отпустите — отправится.
  Клавиша регистрируется только на время карточки, в остальное время она свободна для других программ.
- `Ctrl+Alt+P` — карточка прямо сейчас. Клик по иконке в трее — то же самое.
- Попытка 1 — без субтитров, попытка 2 — с португальскими субтитрами, потом показывается перевод.
- Интервалы повторений — FSRS. Не переведённая фраза помечается трудной и возвращается
  через `relearn_minutes`; флаг снимается после трёх верных ответов подряд.

## Синхронизация с телефоном

Встроенная, по локальной сети, без сторонних программ: программа в трее отвечает телефону
(UDP 47811 — поиск, HTTP 47812 — данные). Подробно — [docs/ANDROID.md](docs/ANDROID.md).

- Трей → «Подключить телефон…» — QR-код с адресом ПК, ключом сопряжения и ключами API.
- При первом запуске Windows спросит про доступ к сети — разрешить для частных сетей.
- Выключить: `[sync] enabled = false` в `config.toml`.
- Проверка без телефона: `cargo run --release -p harvester -- phone-sim --dir <папка>` — изображает телефон
  с пустой базой, находит ПК и синхронизируется.

## Android-приложение

```
cd crates/mobile
cargo tauri android build --apk --target aarch64            # релизный APK (~10 МБ)
cargo tauri android build --debug --apk --target aarch64    # отладочный (~180 МБ)
```

APK: `crates/mobile/gen/android/app/build/outputs/apk/universal/release/app-universal-release.apk`.

Подпись: ключ `%USERPROFILE%\.teach-meelease.jks`, пароль — в `crates/mobile/gen/android/keystore.properties`
(оба не в git). **Сохраните копию ключа**: обновление ставится поверх старой версии только с той же подписью;
с новым ключом придётся удалять приложение (локальные данные телефона пропадут — перед этим синхронизироваться с ПК).
